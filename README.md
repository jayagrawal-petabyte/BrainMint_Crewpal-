# CREWPAL - Task Management Frontend

A beautiful, high-performance, responsive task management frontend application built with React, Vite, Tailwind CSS v4, and Zustand.

## 🚀 Features

- **Kanban & List Views:** Seamlessly switch between a vertical task list, a kanban board, and a due date calendar view.
- **Drag & Drop:** Fully functional drag-and-drop kanban board for managing task statuses.
- **Dashboard:** At-a-glance analytics with priority distribution and recent activity.
- **Subtasks & Comments:** Drill down into tasks to manage checklists and collaborate via comments.
- **Sorting & Filtering:** Sort tasks by due date, priority, name, or created date, and quickly search across all tasks.
- **Smooth Animations:** Delightful micro-interactions, layout transitions, and toast notifications.
- **Responsive Design:** Mobile-first architecture that scales perfectly to tablets and desktop screens.
- **Accessibility:** Screen reader friendly, ARIA labeled modals, and keyboard navigable task cards.

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS v4
- **State Management:** Zustand
- **Icons:** Lucide React
- **Routing:** React Router v7

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation

1. Clone the repository and navigate to the frontend directory:
   ```bash
   cd worktrack-frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
